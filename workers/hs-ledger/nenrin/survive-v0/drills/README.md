Reports written by .github/workflows/survive-drill.yml. latest-*.json is the newest run for each source; history.jsonl has one line per run. Red runs stay.

swh-cook-ahead.json (2026-10-30) is the copy each run asks the Software Heritage vault for at its end. The next run uses that copy when the vault has it ready, and says so in the report (source.cooked_ahead.used). The record keeps the requests of the last four days (up to five; 2026-11-04, when the vault took up to two days per request), and the run uses the newest one that is done, naming its day. A request older than four days is not used. When none is ready, the run cooks the latest visit and waits, as before.
