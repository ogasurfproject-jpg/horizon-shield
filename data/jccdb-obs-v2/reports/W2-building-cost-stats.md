## 結論

- 建築着工統計調査(国土交通省、e-Stat の Excel)の 都道府県 x 構造(第６表－１)と 都道府県 x 用途大分類(第７表－１)を、令和7年計(2025)と 令和8年1月〜7月の各月について取り込んだ。建築物の数・床面積・工事費予定額を原本の値のまま別行で持ち、1㎡あたり工事費予定額を自分で割って cost_per_m2 行にした(割る前の2行の obs_id を note に記載)。

## 4. 原本の誤植らしきもの

**建設工事費デフレーター(2020年度基準)の四半期別シートと年度別ファイルの列ずれ**

- 範囲: 四半期別は 2020年4-6月期以降、年度別は 2021年度以降、列は「地方道路公社等」(月別シートの AS 列)から「S事務所・その他」(BY 列)までの33系列。
- 四半期別(825 セル): 同じ系列の月別平均と一致 155、**左隣の系列の月別平均とだけ一致 650**、どちらとも不一致 20。範囲外は 2,250 セルすべて一致。
- 年度別(165 セル): 同じ系列と一致 15、**左隣の系列とだけ一致 146**、どちらとも不一致 4。範囲外 585 セルはすべて一致。
- 四半期別の4期平均と年度別は範囲内でも全セル一致するので、ずれているのは四半期別と年度別の側で、月別シートは正しいと判断した。根拠: 2021年度の月別平均は 木造住宅W 110.3 に対し W在来住宅 110.2・W量産住宅 114.1、鉄筋RC(住宅) 105.2 に対し RC在来住宅 105.2・RC量産住宅 106.1 と、合成指数が個別指数の範囲に収まる。年度別ファイルの値(W在来住宅 103.5、W量産住宅 110.2、RC在来住宅 114.1)ではこれが成り立たない。
- 扱い: 値は原本のまま published_pdl で載せ、該当する四半期別 825 行・年度別 165 行の note に「1列右にずれている疑い」を書いた。利用者は月別を使うのが安全。国交省(建設経済統計調査室)への照会を勧める。

## 5. 取れなかったもの・やらなかったもの

- 着工統計 第３表(用途別、構造別、全国): 2025年計 1,738,240 bytes、2026年7月分 660,992 bytes。website-content-crawler では取れたが、MCP の get-key-value-store-record は約256KB を超えるとリンクだけを返し、そのリンク先 api.apify.com はこの環境の proxy が 403 で拒む。そのため **都道府県 x 構造 x 用途 の3元の表は無い**(e-Stat のファイルにも都道府県x構造x用途の表は無く、第６表(都道府県x構造)と第７表(都道府県x用途)の2元の表だけ)。

- 建設工事費デフレーター 2015年度基準: 2026年4月分から2020年度基準に置き換わったため取っていない(旧基準は e-Stat の過去資料にある)。参考値(後方3か月平均、002018222.xlsx)は取得したが、月別から計算できる値なので取り込んでいない(raw にも置いていない)。
- e-Stat の .xls には HTTP の Last-Modified を取れていない(website-content-crawler は応答ヘッダを返さない)。
