## 読み方

- 共通(mlit_grid.py): 語は pdftotext -bbox-layout の座標、罫線の位置は pdfplumber(線の座標だけを使う)。行 = 単位の列と値の列を横切る横罫線で区切った帯、列 = 最初のデータ行を縦に横切る縦罫線で区切ったセル。複数行にわたるセルは帯ごとにまとめ、前の行がセルの右端近くまで埋まっていれば折り返しとみて空白なしでつないだ(例: 「排水性対」+「応型」)。
- 列見出し: 見出し帯の語のうち 1 つのセルに収まる語。2 段の地区名は「野津原 / 挟間」のように ' / ' でつないだ。県名の群ラベルは、ラベルの高さまで伸びる縦線でラベルの範囲を決めた。群ラベルの無い地区は 0 件、1 つの地区名が 2 県に属する矛盾は 0 件(東北の「雄勝」は宮城県と秋田県に同名の別地区が実在し、地区設定一覧表と一致)。
- 空欄のセルは行を作らない(九州・東北・沖縄とも、原本が「物価資料の価格」と「価格を設定していない」を区別しないため。九州は area_quote に原文)。
- 備考は spec の末尾に [ ] で付けた(近畿の見本と同じ)。北海道は 摘要１・摘要２ を spec の [ ] に、荷渡条件を note に。
- 九州 105-109 頁と 133-134 頁の「備考（参考重量〈kg〉）」の県別の列、242-243 頁の「参考重量（kg）」の列は値にせず、同じ県の値の note に「参考重量(kg): …」と書いた。
- 九州 242-243 頁の表の中の「※条件」(受取場所 工場裸渡し、荷造り費 含まず、支払い条件 現金、消費税 含まず)は、同じ種別・同じ格子の頁の行の note に書いた。生コンの頁の頁下の注記(「※備考欄にW/C…を掲載しています。」)も note に。
- 消費税: 北海道は原本に「含まない」、九州 242-243 頁は「含まず」、東北 76 頁は「含まず」。ほかは表に明記が無いので note に「消費税の扱いは表に明記なし(国の積算の材料単価は税抜き)」と書き、price_basis は design_unit_price_ex_tax とした。
- 値が 0 のセル(北海道 90、沖縄 3 = 備考「市場性なし」)と、値の欄が文字のセル(九州 105 頁「本体に含む」1)は not_set とし、原文を note に。北海道の金額欄「-」738 は publication_based_not_public。北海道の「＊」は今回の版に 0 件。
- layer: 北海道の市場単価(04-xx)1,610 は work、機械の賃料・損料(02-85, 03-03, 03-05, 07-05)で単位が時間・日・月のもの 350 は equipment(hourly 40 / daily 300 / monthly 10)。九州 247 頁「測定機器賃料」(単位 日)7 は equipment daily。東北【工事費】(路面標示用自転車マーク)6 は work。仮設材の賃料(仮設ガードレール賃料 など)は機械でないので material のまま。
- 北海道の労務の表(01-01 労務賃金、01-02 設計業務等賃金、01-03 電気通信関係技術者賃金、01-04 工場製作労務)77 行 = 770 セルは取り込んでいない。
- 地区: 九州 area_members は別表「地区割り一覧表」(3-4 頁)の適用市町村名を原文で(105 地区、単価表の地区は全部対応がついた。注）１・注）２ の本文も [ ] で添えた)。北海道の地区は開発建設部(札幌〜稚内)で、管内の市町村は PDF に無い。沖縄の「Ⅱ 資材単価区域図」は画像だけ(51 頁)で文字が取れないため area_members は空。
