何が起きたか

gate.horizonshield.dev の A2A agent card は version を持つ。運営者が版を 0.4.8、0.4.9 と 2 回上げ、2 回とも card に署名し直さずに撒いた。日次の証人 (drift witness) が初回の走りで、配られとる card が署名と合わんことを見つけた。規則 R3 が「署名し直せ (resign_agent_card)」を提案し、「撒き直せ (redeploy_pinned)」を「署名の無い本体をまた撒くだけ」と却下した。運営者が Ed25519 の運営者鍵で許可に署名し、署名し直して、門 (deploy_gate.sh) 経由で撒き直した。証人がもう一度測って 0 drift。以後、署名の合わん version は門で止まる (test/card_signature)。

外部の証人 (Agenstry) が 09-19 に見つけた 1 件目は、原因が別 (生 deploy) やった。今回は彼らの読み「変更のたびに署名し直せ」がそのまま当たっとる。両方とも記録に残しとる。
