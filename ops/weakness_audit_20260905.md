## 構造(約束と実装の差、4)

**5. 自己測定が pending のまま。誰も外から扉を測っとらん。**
`/self` は「自分の /mcp に届かん、外から測ってくれ」と書いて何週間も pending。**測る側の行が未測定のまま**の計器を、他人がどう信じる。
→ 直し: 4 と同じ。外部 witness 1 人で解ける。

**6. 0.3.0 は未証明。beacon が外部 2 社の API に依存。**

→ 直し: 今夜の結果を見る。落ちとったら 3 源目(例: blockchain.info)を足すか、header 同期を offline で回して KV に置く道(管理口が要る)を再検討。

**7. 「反証可能」やが誰も反証しとらん。**
判定に height と hash を刻んで「手元にヘッダを持つ者が反証できる」と書いた。**手元ヘッダで beacon を自動照合する処理が無い。** 反証できる状態と、反証されとる状態は別物や。
→ 直し: coordinate-v1 の localheaders.py に「登録簿の全 beacon を手元ヘッダと突き合わせる」を 1 本足して、週次巡回に入れる。
