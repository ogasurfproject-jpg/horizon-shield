見えない工事シリーズ ・ 見積もりの読み方

リフォーム・リノベの「無料一括見積もり」は、なぜ落とし穴なのか → リフォーム相場の「根拠」には2種類ある。あなたが見るべきはどちらか → 見積もりの「一式」って大丈夫？内訳の出させ方 → 工事中の「追加請求」、払う前に確認 → 屋根の飛び込み営業、その場で契約するな → 相見積もりは「総額」でなく「単価」で比べる → 給湯器が急に壊れた、即決する前に → ノーリツ給湯器の交換費用と現行型番一覧（公式照合済み）→ 外壁塗装の契約、サインする前に確認 → 工事中のトラブル、種類別の対処法 → 悪質リフォーム業者の見分け方（総まとめ）→ 外壁塗装の見積もり、これって高いの → 屋根の修理の見積もり、これって高いの → 床下のシロアリ消毒、その見積もりは高いのか → 床下換気扇の見積もり、その台数は本当に必要か → 床下で基礎にヒビと言われたけど、これって高いの → 床下調湿剤の見積もり、その工事は本当に必要か →
