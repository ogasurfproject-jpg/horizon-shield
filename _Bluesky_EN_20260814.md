# Bluesky — 英語 2026-08-14

## Bluesky はここが違う

| | |
|---|---|
| **1投稿300字** | grapheme 単位。URL も文字数に入る |
| **リンクを罰しない** | LinkedIn と違い、本文に URL を入れてよい。最初のコメントに逃がす必要がない |
| **alt テキストは事実上の必須** | 画像に alt を付けないのは、あの場所では無作法とみなされる |
| **読者層** | 技術者・研究者・AI に懐疑的な層。**宣伝口調に最も厳しい場所** |
| **ハッシュタグ** | 効くが、使いすぎると即座に安く見える。**0〜1個** |

**LinkedIn 版をそのまま貼らないこと。** あれは長文前提の文体で、Bluesky では冗長に見える。

# B. 単発版（1投稿だけで済ませたいとき）

スレッドより拡散しやすい場合がある。**画像を必ず添付する。**

```
Last month our MCP server appeared in 93,983 search results. It was used zero times.

Agents can find software now. They can't tell which result is what it claims to be. That's the whole gap.

So we built a checker and pointed it at ourselves first. Our own verdict: pending.
```

リンクは**返信として自分でぶら下げる**:

```
Free, no account, no API key, ten seconds. It calls no tool on the server you point it at.

shield.the-horizons-innovation.com/verify-directory/
```

# C. 画像の alt テキスト（必ず入れる）

```
Two figures side by side on a dark background. On the left, in white:
93,983 search results. On the right, glowing gold: 0 tool calls. Small grey
text along the bottom reads "Glama dashboard, 30 days to 2026-08-14".
```

**Bluesky で alt を省くのは、技術者コミュニティでは減点される。** そして**この投稿は「測ったことしか言わない」という話**なので、画像の中身を言葉で残さないのは筋が通らない。

# D. やらないこと

- **ハッシュタグを並べない。** 付けるなら `#MCP` 1個まで
- **「試してください」と繰り返さない。** 1回でいい
- **LinkedIn 版の長文をそのまま貼らない**
- **投稿直後に他所へ「見てくれ」と書かない**

# E. 投稿後

**最初の60分は張り付いて、リプライに全部返す。** Bluesky はリプライの往復が可視化されやすく、**会話が起きた投稿だけが伸びる。**
