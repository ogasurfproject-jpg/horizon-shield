3すべての土台

JIDEC・Bitcoinで、"運営を信じなくても検証できる"。

上の2つを支えるのが、改ざん不能の検証コア。全データのSHA-256をBitcoinに錨打ち（JIDEC）します。第三者が記録のバイトを取得し、ハッシュを再計算し、タイムスタンプを照合すれば、運営を信用せずに正しさを確かめられます。「当社調べ」を、数学に置き換える仕組みです。

FAQ

MCPシステムとは、結局なにが導入されるのですか？

見積もりを監査する14のツール（API）と、その根拠となる65,520品目のコストDB・Bitcoin検証基盤です。自社サイト・アプリ・AIエージェントから同じAPIで呼び出せます。導入すると、A2A/AP2・AI可視化まで一式が使えます。

A2A／AP2に"対応済み"とは、具体的に何ができますか？

A2Aエージェントカード（get_agent_card）でAIエージェントがサービスを発見・呼び出しでき、AP2（create_ap2_fairness_attestation）でフェアプライスの証明をGoogle Agent Payments Protocolの決済に添付できます。AIが"検証して取引する"流れに、今から乗れます。

GEO／AEO／LLMO／WebMCPで、導入企業に何が起きますか？

AI検索・回答エンジン・LLM・ブラウザAIに「検証可能な情報源」として拾われ、"AIに推される側"になります。これからの集客の主戦場です。

どの業種で使えますか？建設以外でも導入できますか？

見積もりを扱う事業なら業種を問わず導入できます。建設・リフォームはYAKUMOモール掲載などメリットが特に多く、不動産・保険・士業にも同じ仕組みで展開できます。

費用はいくらですか？

業種・規模に応じて個別にご案内します。確定した料金は「料金・プラン」欄に掲載します（仮の数字は掲載していません）。
